# 主笔写戏

## 拿到这场戏

读创作者的创作意图、篇幅、可用演员或场景，以及这场之前最后发生的动作。续作取真实上场原文和有关的人物知情范围。把用户喜欢的一小段自己的样稿当作语气参照。只把会改变这场戏的事实交给主笔。对用户提供的原著区分真事、人物相信的事、改编新加的事。

用一句人话想清“此刻谁想让谁做哪件具体的事，他为什么偏偏不肯”。有时一人只想趁另一个人没发现，把桌上多摆的那只碗收起来。允许人物装作在忙别的。遇到两难，把选择落在手上能做的动作上。安静场可以在观众对同一动作有了新理解时结束。

默认直接写一版可排练的正文，从局面已经开始变化的地方入场。沿用用户原稿格式。无指定格式时给场景、时间、动作、人物对白。对白长度依人物处境而变，容许答非所问、半句、礼貌话，也容许一个人把一句话说完。让对手听见后能做出不同的反应。末尾停在动作产生后果的那一刻。按用户意图决定悬念、笑点、刺痛或余味。不要给每场都配反转和金句。

## 把书用在稿上

沿用项目五书知识库与当前已启用卡。遇到具体难题再取相关卡，通常传给主笔零至两条。正稿计划阶段仍可检索更多候选卡。如“中段三次劝签都能互换”，用结构方法找出第二次新增的诱因或代价；“一个人何时改变主意”，可用麦基《故事》的期待与结果落差，把发现放到改口前一拍；“台词像互相解释剧情”，用言语行动定位一句话想逼对方做什么。只记真正改变了哪一集、哪个动作的卡片。未安装的卡不得冒充已调用。

例：姐姐说“我尊重你的决定”，弟弟只好点头，演员很难演出代价。若已知她一直替弟弟签字，可改成她下意识接过笔，在签名栏上停住，把表转回他面前。他把表转回来：“你先把手松开。”这一动作适用于这段关系，换题材时重新找动作。

## 委派与返修

用户要求主流程与写作分开选模型时，向 drama_writer 单独委派本场或本批的创作。给主笔场景任务、锁定事实、上一场最后动作、角色各自掌握的信息、允许发明的空间和交稿格式。局改给原段及上下文，标清哪些句子必须保留。优先从干净上下文交接。主笔回传完整正文，主会话逐字交付获选稿；文件写入、换行和编号可由主会话处理。修台词时把具体问题送回同一主笔。不要让汇总代理再合写一次。

本地 Codex 项目可在项目根使用 .codex/agents/drama-writer.toml。配置随本项目加载；只把 Skill 装到另一个写作项目时，需把这份配置放在实际写作项目的相同位置，再让运行该项目的 Codex 加载。文件中的 name = "drama_writer" 是委派名称，文件名本身不决定代理名；必填字段与模型配置见 [Codex 自定义代理文档](https://learn.chatgpt.com/docs/agent-configuration/subagents#custom-agents)。默认示例选 gpt-6.2-astra 与 medium，可改为账号实际可用且盲读更喜欢的模型。普通主会话保持输入框选定的模型；具体模型由实际启动的子代理配置决定。配置未加载、工具不支持该代理或显式委派失败时如实报告原因，给出在当前会话切换可用模型继续的选项，不静默代写并冒称独立主笔。只有真实子任务返回后才报告为独立主笔作品。审稿人先读稿再看事实，只交原句、读者疑问、受影响的后文。审美分歧交创作者决定。

## 盲读与选版

选择一场安静的关系戏和一场有信息差的对抗戏。先用同一可选模型、同一事实包、篇幅和修改轮数，各写直接对话版和本 Skill 版；再固定本 Skill，只换主笔模型。每组随机标甲乙，第二场调换阅读顺序，作者说明在选完后揭示。读者圈出一个愿意留下的动作或一句会删掉的台词，指出人物在哪一拍换了做法、触发点是否在正文可见、哪里想继续看。记录偏好、持平或各有长处，并单列事实错误。采纳胜出片段和理由作为下次的项目风格参照。
