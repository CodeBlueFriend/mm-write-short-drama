# 原创故事发现

接受一句创意、题材、人物、冲突、结局或完整梗概作为入口。输入太宽时只给三个差异明确的方向，每个方向说明核心情绪、故事引擎和主要代价。

## 必须产出

1. **一句话命题**：主角在什么压力下采取什么行动，失败代价是什么。
2. **欲望、需求、致命阻碍**：外部目标、内在缺口、持续阻力不可互相替代。
3. **故事引擎**：解释冲突如何自然产生并可持续升级，而非只有一个开场噱头。
4. **核心关系**：双方互相需要、互相妨碍的具体机制。
5. **主要对抗**：对手也有自洽目标、资源和升级能力。
6. **升级方式**：至少覆盖资源、关系、信息、身份、时间压力中的两类。
7. **结局承诺**：明确最终要回答的情感与价值问题。
8. **题材差异化**：避免只更换职业、城市或身份标签。

## 发现检验

- 去掉巧合后，主角的选择还能推动故事吗？
- 每次胜负是否改变资源、关系或信息状态？
- 主要关系能否制造亲密与冲突两种动力？
- 反派/阻力是否会学习并调整策略？
- 结局是否兑现开场承诺，而非临时另起主题？

候选结论属于 L3，用户确认并写入故事圣经后才升为 L0/L1。
