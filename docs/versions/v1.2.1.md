# mm-write-short-drama v1.2.1

现在装一次短剧编剧技能，就能拿到 Humanizer 规则和交付校验工具。从立项到批次 Word 导出，都用同一个技能。

## 安装

把这条指令粘贴到 Codex。

```text
$skill-installer 从 https://github.com/CodeBlueFriend/mm-write-short-drama/tree/v1.2.1/mm-write-short-drama 安装技能
```

已经安装旧版时，先备份原技能目录，再按 [首页手动安装步骤](../../README.md#安装) 更新同一个技能目录。现有项目、个人知识库及与当前稿件匹配的审核记录可以继续用。

Word 需要 Python 3.10+ 和 `python-docx`。工作区如果缺包，首次导出可按随技能提供的清单联网装进项目虚拟环境。版式目检使用现有文档工具。[Word 导出环境](../../mm-write-short-drama/references/word-delivery.md#准备-word-导出环境)

## 写作能力

首页列出已整理的四本书和对应的五项短剧能力。可以点名要查的环节，例如一句梗概、整季节拍、秘密揭露、集尾与下集开场的承接，或对白中的言语行动。[查看书目、示例与来源状态](../../README.md#四本书对应的五项写作能力)
