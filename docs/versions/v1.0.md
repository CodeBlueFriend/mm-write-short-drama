# mm-write-short-drama v1.0

发布日期：2026-08-06

Git 基线：`79a3ae25c2bbcbd1b0d1d4aead551caee4e12cff`

v1.0 建立短剧编剧 Skill 的稳定工作流。它适合从一句创意、人物、故事、小说或梗概开始，逐步形成可进入制片或分镜环节的完整剧本。

## 核心功能

- 原创路线：创意澄清、原创故事发现、故事圣经、整季结构、分集矩阵、场次卡、剧本和审核。
- 改编路线：原文索引、原著事实库、改编映射、故事圣经、整季结构、分集、剧本和忠实度审核。
- 连续性管理：维护人物、信息、时间线、道具和伏笔账本。
- 分批写作：按 3—5 集生成最小上下文包，完成后回写项目状态。
- 质量控制：检查结构、人物、连续性、台词、AI 味和制作风险。
- 协作控制：支持严格确认、辅助确认和自动推进。

## 安装 v1.0

需要复现旧版时，可以检出 v1.0 标签并复制 Skill：

```bash
git clone https://github.com/CodeBlueFriend/mm-write-short-drama.git
cd mm-write-short-drama
git checkout v1.0.0
mkdir -p ~/.codex/skills
cp -R ./mm-write-short-drama ~/.codex/skills/mm-write-short-drama
```

重新打开 Codex 或新建任务，让 Skill 列表刷新。

## 原创短剧示例

```text
$mm-write-short-drama 原创一部 12 集女频悬疑短剧，单集 90 秒，竖屏、低成本真人拍摄。
核心人物是一位替老人整理遗物的年轻遗物整理师。
采用严格确认模式，先完成项目启动单和故事圣经，不要直接写剧本。
```

## 小说改编示例

将有权使用的小说 `.md` 或 `.txt` 放入工作区后使用：

```text
$mm-write-short-drama 把 ./source/novel.md 改编为 24 集竖屏真人短剧。
先索引原文，区分原著事实、合理推断、改编决定和待确认项。
本轮只交付原著事实库、改编映射和故事圣经。
```

## 常用脚本

```bash
# 初始化原创项目
python3 mm-write-short-drama/scripts/init_project.py ./projects/demo --mode original

# 初始化改编项目
python3 mm-write-short-drama/scripts/init_project.py ./projects/demo-adaptation --mode adaptation

# 校验项目状态
python3 mm-write-short-drama/scripts/validate_project.py ./projects/demo
```

## v1.0 的边界

v1.0 的编剧技巧属于 Skill 自带参考资料。它没有独立的个人知识库，也没有规则查重、冲突裁决和阶段化检索。需要长期录入个人编剧经验时，应升级到 v1.1。

升级步骤见 [v1.1 使用说明](v1.1.md)。
