# 短剧编剧插件隐私说明

维护者为 CodeBlueFriend。本插件通过 ChatGPT 或 Codex 中的技能协助处理短剧创作任务，使用你在对话中提供或允许读取的创意、剧本、参考材料和项目文件。相关内容用于策划、编审、连续性记录和 Word 导出。

项目文件和交付件写到你指定的工作区。交付审核可能在项目内保存原稿快照和定稿哈希，供下一次导出时验证。插件没有维护者运营的数据接收服务器或遥测脚本，维护者不会通过插件收到你的剧本、私人知识库或项目文件。

ChatGPT 或 Codex 对提交给服务的对话和文件按 OpenAI 的隐私政策处理，保留时间和数据控制取决于使用的产品及工作区设置。你可以选择提供哪些材料，控制工作区访问，并在本地管理或删除项目文件与审核记录。首次导出缺少 Python 依赖时，按导出说明访问包源下载依赖，包源按自身政策处理下载请求。

如果你主动在 GitHub 提交反馈，GitHub 按其隐私政策处理你提供的内容，公开 Issue 可被其他人查看。反馈请使用可公开的示例。
