# 一项大纲决定如何落到可演的戏

《旧伞借还》是这次工作流升级时实际新写、审读和导出的公开合成示范。它不改编用户剧本。大纲确认由软件夹具模拟，不能视为创作者对真实项目的批准。

## 输入与结构决定

临行女儿许岑把借坏的黑伞送回母亲许绣的修伞铺。母亲一开始就建议剪开旧布换骨；女儿希望看不出修过，改用铁丝，结果勾住母亲的袖子。

大纲决定 `UMBRELLA-outline`：让女儿在“赶已经付费、不可退改的拼车，把坏伞留给母亲”与“承担车费损失、拆自己的红伞，留下共同修好”之间选择。明早普通车仍赶得上报到，正文提前说明这一条件。代价是实际损失，不能夸成失去工作。母亲接回原先提出的修法，随后交针让女儿参与；不新增母亲拒剪的动机。

这次选择采用 `cap.mckee-story-short-drama.crisis-choice`，实际卡片 `RULE-A2FBF4BF0A`，上游修订2、库内编辑版本1，来自 [固定提交的导入稿](https://github.com/CodeBlueFriend/short-drama-book-skills/blob/6e99009572a64f99d60134405fbf1cf200b0dfe4/knowledge-inbox/story-05-crisis-choice.md)。没有隐瞒驱动，因此跳过人物秘密方法。卡号只留在工作资料里。

## 分集与场次交付

第一集以铁丝已剪、断骨仍翘在原布下结束。第二集先把废铁丝放入盒中，出发提醒响起，立即承接尚未解决的修法和行程。

第二集场次的动作链是：关提醒、打电话取消等待、拆自己的红伞、把长骨推给母亲、问补布尺寸、一起换骨缝补。女儿已经付出资源，接下来做事的方式也随之改变。

以下是实际成稿中的片段：

```text
许绣：车来了。
▲许岑关掉提醒，拨通电话。
许岑：师傅，不等我了。车费按说好的，不退。
▲她挂断电话，把红伞撑开，卸下其中一根长骨。
许绣：你把它拆了，明早用什么？
许岑：明早坐普通车，还赶得上。伞先借你的。
▲许岑将红伞折好放到脚边，把长骨推给母亲。
许岑：剪开这儿，补多大一块？
```

## 对白与结局复检

第一集的“我接一下。看不出来就行”，到第二集变成“剪开这儿，补多大一块？”前句要求消除痕迹，后句开始参与如何留下痕迹。母亲不替她讲主题，只指导“沿着这排眼，别拉太紧”。

结尾女儿说“还你了”，母亲将修好的伞再次借给她。红补丁、损坏的红伞和已经作废的当晚车费都保留；安静的缝补改变了两人的协作方式，未被作为节奏问题删除。审读曾发现前置把拒剪错误归给母亲，已据正文返修，重审后导出。这个例子证明有可追溯的实际产物，不代替匿名对照对创作效果的判断。
