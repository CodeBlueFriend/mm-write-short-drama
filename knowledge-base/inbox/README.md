# Inbox

把待录入的 `.md` 或 `.txt` 文件放在这里。批处理脚本只读取和复制，不移动、不改名、不删除原文件。

推荐每条技巧使用一个项目符号，或使用下面的半结构化格式；多条规则用 `---` 分隔：

```text
技巧名称: 首次有效反击
规则: 主角第一次有效反击必须改变资源、关系或信息状态，不能只获得口头胜利。
理由: 状态变化才能让反击影响后续因果。
分类: 分集与卡点
阶段: episode
题材: 女频复仇
制作形式: all
优先级: preferred
例外: 经确认的前期压抑型结构
正例: 女主公开账本后夺回项目表决权。
反例: 女主只把反派骂走，局势没有变化。
```
